# Daily Notes / 每日便签

A quiet, edge-docked desktop companion for tasks, schedules, focus and everyday information.

Daily Notes is a proprietary desktop productivity product under active development. This repository contains selected public development history, product milestones and provenance records. The production source code is proprietary and maintained privately.

## Visible Windows desktop milestone

By 2026-10-04, the recorded Windows desktop milestone included:

- An edge-docked desktop workspace with auto-hide and hover reveal.
- Draggable edge tabs for navigating between views.
- Todo, Calendar, Month and Review / completion history.
- Today Overview with draggable, reorderable overview widgets.
- Pomodoro / Focus and optional health reminders.
- An AI usage overview.
- Local persistence, backup and restore.
- A desktop-oriented modular interface.

Daily Notes is designed as a modular and extensible desktop experience.
